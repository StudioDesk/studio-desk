# To-do list sample

A small to-do list library to try Studio desk on: you can add items, mark one done, and list what is left. It has no dependencies.

- `src/todo.js` holds the list.
- `test/todo.test.js` holds its tests.
- `package.json` names the library and its test command.

Run the tests with:

```
npm test
```

Studio desk made this repository as a sample, in your Studio desk data folder. Send it an idea from its New idea box and watch the agents plan the change, make it, test it and review it before it goes in.
